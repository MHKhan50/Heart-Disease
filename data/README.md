# Data

Data files are not committed to this repository.

Source: UCI Heart Disease databases (Cleveland Clinic Foundation; Hungarian
Institute of Cardiology, Budapest; V.A. Medical Center, Long Beach;
University Hospital, Zurich). The 14 commonly used attributes are used, and
each row keeps the hospital it came from so that cross-hospital validation is
possible.

Place the downloaded CSV here as `data/heart_disease_uci.csv`, or attach the
corresponding Kaggle dataset when running the notebooks on Kaggle.
